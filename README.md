# Appendix — Ada-Extractor

Supplementary appendices of the paper **Ada-Extractor: Long-Text Factual Hallucination Correction via Adaptive Entity Anchor Extraction**.

This repository contains the appendix material of the paper as a set of standalone Markdown files. Each file covers one appendix section of the paper, follows the same structure (numbered sections, numbered tables, unified notation), and can be read independently.

## Contents

| Appendix | File | Topic |
|---|---|---|
| A | — (overview section in the paper) | Appendix overview: states that the complete supplementary materials are hosted in this repository and briefly introduces Appendices B–F |
| B | [Entity-Anchor Concentration](Appendix_B_Entity_Anchor_Concentration.md) | Empirical analysis of entity-anchor concentration (96 passages, 4 domains, 4 length bins) |
| C | [Experimental Stability Analysis](Appendix_C_Experimental_Stability_Analysis.md) | Across-run standard deviations over 20 independent runs |
| D | [Discourse Coherence Evaluation](Appendix_D_Discourse_Coherence_Evaluation.md) | Blinded human evaluation of discourse coherence |
| E | [Cross-Domain Generality](Appendix_E_Cross_Domain_Generality.md) | Cross-domain generality validation on three additional long-text genres |
